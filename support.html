Quick help

System requirements

FoodPhotos requires an iPhone running iOS 26 or later.

Photo access

Open iOS Settings, select Apps, select FoodPhotos, and review Photos access.
Full Access allows the app to scan the complete library. Limited Access restricts scanning to the photos you select.

A scan appears stuck

Keep FoodPhotos active while it analyzes authorized photos. Large libraries and iCloud downloads can take time.
Use the scan status control to pause and continue. Failed items can be reviewed and retried from Settings.

A food photo is missing

Confirm that the photo is included in the current Photo Library permission.
The classifier is conservative and may miss some food photos. Recognition accuracy is not guaranteed.

Map location

Enable location access in iOS Settings if you want the map to center on the current location.
Photos without valid location metadata do not appear as photo groups on the map.

Removing album items

Removing a photo through FoodPhotos changes only its membership in the FoodPhotos album. The original photo remains in the system Photo Library.

iCloud photos

Apple PhotoKit may need to download an authorized iCloud photo before local analysis can continue. Check the network connection and available device storage.

Report a problem

Include the following details so support can reproduce the issue:
  • iPhone model and iOS version
  • FoodPhotos version and build number
  • The steps that caused the problem
  • The result you expected and the result you saw
